## Тонкости реализации:
### Лёгкость добавления фигур:
Для реализация данной фичи код построен на основе паттерна программирования "Фабричный метод".
Для добавления новой фигуры нужно создать новый класс данной фигуры, который будет наследоваться от Shape. Также нужно будет создать класс Creator фигуры, который наследуется от FigureCreator
#### Структура классов:
- Shape - представляет из себя абстрактный класс, от которого наследуются фигуры. Он содержит в себе метод area(), который
должен быть переопределён к классах наследниках (пока это Circle и Triangle, но в будущем можно спокойно добавить ещё что-то)
- Circle и Triangle - классы фигур, которые содержат в себе конструктор и соотв. методы для подсчёта площади. В конструкторе есть проверка на корректность
передаваемых данных. Также метод Triangle содержит проверку на прямоугольный треугольник на основании теоремы Пифагора
- FigureCreator - абстрактый класс (своего рода фабрика), который содержит в себе метод create_figure. Данный метод должен быть переопределён в наследниках
- CircleCreator и TriangleCreator - фабрики по поставке кругов и треугольников. Они инкапсулируют в себе логику создания соотв. объектов


### Unit-тестирование:
Для реализация Unit-тестирования была использована библиотека PyTest. Все тесты хранятся в test_figures.py

#### Что проверяется:
- корректность подсчёта площадей
- работа программы в случае передачи некорректных данных
- работа фабрик по созданию объектов соотв. фигур

### Вычисление площади фигуры без знания типа фигуры в compile-time
Это реализовано за счёт наследования и полиморфизма. Каждая фигура является объектов типа Shape.

Реализация данной фичи есть в классе Triangle. Реализовано это на основании теоремы Пифагора
